# Keybindings

Prodi9al Hyprland Config keybindings are defined in `Configs/.config/hypr/hyprland.lua`.

## Super Key

The `SUPER` key (Windows key) is the primary modifier.

## Window Management

| Keybinding | Action |
|------------|--------|
| SUPER + Q | Kill active window |
| SUPER + C | Close active window |
| SUPER + M | Toggle floating |
| SUPER + F | Toggle fullscreen |
| SUPER + E | File manager (dolphin) |
| SUPER + RETURN | Terminal (kitty) |
| SUPER + R | Rofi menu |
| SUPER + B | Browser |
| SUPER + V | Clipboard manager |

## Workspaces

| Keybinding | Action |
|------------|--------|
| SUPER + 1-10 | Switch to workspace |
| SUPER + SHIFT + 1-10 | Move window to workspace |
| SUPER + TAB | Previous workspace |

## System

| Keybinding | Action |
|------------|--------|
| SUPER + SHIFT + E | Exit Hyprland |
| SUPER + SHIFT + R | Reload Hyprland config |
| SUPER + SHIFT + Q | Kill all windows |
| SUPER + SHIFT + L | Lock screen |
| SUPER + SHIFT + P | Power menu |

## Volume & Brightness

| Keybinding | Action |
|------------|--------|
| VOLUME_UP / VOLUME_DOWN | Volume control |
| VOLUME_MUTE | Toggle mute |
| BRIGHTNESS_UP / BRIGHTNESS_DOWN | Brightness control |

## Screenshots

| Keybinding | Action |
|------------|--------|
| PRINTSCREEN | Full screenshot |
| SHIFT + PRINTSCREEN | Area screenshot |

See `Configs/.config/hypr/hyprland.lua` for the full keybinding configuration.
