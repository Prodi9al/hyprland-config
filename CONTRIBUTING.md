# Contributing to Prodi9al Hyprland Config

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/hyprland-config.git`
3. Create a branch: `git checkout -b feature/your-feature`
4. Make your changes
5. Commit and push
6. Open a pull request

## Guidelines

- Follow the existing code style
- Test changes on Arch Linux before submitting
- Keep commit messages concise and descriptive
- Do not commit secrets (tokens, API keys, personal paths)
- Update documentation when adding new features

## Reporting Issues

Open an issue at https://github.com/Prodi9al/hyprland-config/issues
